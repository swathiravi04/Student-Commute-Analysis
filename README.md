
# Student Commute Analysis | Power BI

## Project Overview
An interactive Power BI dashboard designed to analyse student commuting patterns, travel duration, and transportation preferences.

This project explores commuting behaviour through data visualization and interactive reports.

## Objectives
- Analyse student commuting patterns.
- Understand travel duration and distribution.
- Explore different transportation modes.
- Present insights through interactive visualizations.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
